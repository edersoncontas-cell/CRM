# Prompt da apresentação à diretoria — Claude Design

**Como usar**

1. Abra o Claude Design (claude.ai) e comece uma apresentação nova.
2. Anexe o arquivo `docs/APRESENTACAO-DIRETORIA.md`. Se tiver, anexe também o logo da
   concessionária e de 3 a 5 prints reais do CRM (funil, conversa, painel). Sem eles, o
   deck deixa um espaço marcado para você pôr depois.
3. Cole o texto abaixo da linha, inteiro.
4. Antes de mandar o arquivo à diretoria, apague as anotações que começam com
   `[INTERNO]`, ou exporte sem as anotações do apresentador.

Escrito em 27/09/2026 com os números do documento dessa data. Se o documento mudar, os
números deste prompt têm que mudar junto.
